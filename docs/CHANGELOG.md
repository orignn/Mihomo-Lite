# 精简更新记录

当前源码版本：**v0.6.18**。此页按现有版本整理用户可见功能，不包含本地采用、归档或诊断历史，也不代表每个版本都已在 GitHub 提供二进制下载。**目前仓库提供源码；完整安装包将在后续发布后从 [Releases](https://github.com/orignn/Mihomo-Lite/releases) 下载。**

[项目首页](<../README.md>) · [开发指南](<DEVELOPMENT.md>) · [发布指南](<RELEASE.md>)

## v0.6.18 — 简化个性化设置与订阅下载设置

- 个性化设置默认使用日志/DNS 简单表单，高级 YAML 与最终预览默认折叠；只修改实际改动字段，保留其他高级配置，DNS 服务器调整不自动开启 DNS。
- 订阅下载默认显示自动（推荐）、直连、当前代理；UA、条件下载和失败等待收进高级选项，已有策略与数据保持。
- 保留输入与草稿保护；查看、同步或保存下载偏好不触发连接，保存个性化设置后需重新连接。

## v0.6.17 — 面板分区与输入体验

- 增加运行设置、维护页签，简化连接与配置首页；端口、自动连接和备份说明按需展开。
- 调整本机连接信息、订阅表单与窄屏布局；减少浏览器输入历史提示，保留已保存设置与未保存草稿保护。

## v0.6.16 — 独立设置、连接策略与组件维护

- 全局及单份配置可独立保存覆写，提供只读最终配置预览；不改写原订阅，保持本机监听和 TUN 等限制。
- 可选启动连接与有限次数的崩溃重连，默认关闭；手动断开、退出或永久错误停止自动意图。
- 内核与面板从固定官方源检查、下载并核验 SHA-256；下载、安装和回滚分开操作，受控发布目录要求整包维护。

## v0.6.15 — 分享链接与固定端口

- 在本机转换 SS、VMess、VLESS、Trojan、Hysteria2/hy2、TUIC 常见分享格式，不发送第三方转换服务；不支持或冲突的条目整批拒绝，不覆盖原配置。
- 本机端口可自动或固定；固定端口冲突明确报错，端口偏好须退出程序后重新启动才生效。

## v0.6.14 — 订阅下载策略与套餐提示

- 每订阅可选自动回退、直连或当前代理，并设置 UA、条件下载与失败等待；手动和定时更新使用同一策略。
- 流量与到期信息优先取响应头，可补充可识别的节点提示；估算明确标记，缺失与冲突数据不猜测。

## v0.6.13 — 规则模拟与订阅信息

- 规则模拟区分匹配、范围内未匹配与无法确定，不伪造缺失的 Geo/DNS 信息。
- 增加订阅流量/到期显示与订阅地址编辑，候选下载、校验成功后才替换；失败保留原配置。

## v0.6.12 — 配置管理入口精简

- 精简配置卡片操作，保留切换、更新/重试、重命名、删除与完整备份/还原。

## v0.6.11 — 重启后的进程身份核验修复

- 改善旧内核 PID 被其他进程复用时的误阻断；仍以进程身份核验作为安全边界，不因权限拒绝而授权结束其他进程。

## v0.6.10 — 备份还原与草稿保护

- 增加完整配置备份/还原与相关恢复能力；备份可能包含凭据，未加密，不是整个安装目录的镜像。
- YAML 与规则草稿增加未保存提醒；浏览器草稿不能代替配置备份。

## v0.6.9 / v0.6.8 — 统一代理与规则兼容性

- 提供固定的“统一代理”运行层出口，减少切换订阅后策略名不一致；不自动改写源订阅或旧规则。
- 对自定义规则缺失策略提前给出提示，不自动跳过规则或替换为 DIRECT。v0.6.8 的兼容性修复包含于后续 v0.6.9。

## v0.6.7 — 异常会话恢复

- 保存系统代理会话及进程身份，在下次启动时核验旧会话并尝试恢复；身份或代理归属不确定时保守停止，不覆盖其他软件设置。
- 恢复并非即时常驻保护，不能作为全局断网开关。

更早版本逐步提供托盘、静默启动、配置导入、订阅管理与自定义规则等基础能力。具体当前支持范围、TUN 限制与本地隐私警示见 [项目首页](<../README.md>)。
